# Jiaozi-Trail
循交子之迹，览一城风物

独立地图模块 `map-renderer/` 按真实道路与建筑轮廓构建春熙路三维游戏街区，支持平移、旋转、向前漫游、楼宇点击和正北位置核对。楼体采用整墙立面、平滑楼角与连续柔和光照，近处显示店铺和窗台细节。场景读取本地地理快照，无需在线地图 Key；当前建模范围约 1km²，只覆盖太古里西入口，不含完整太古里与大慈寺。

在仓库根目录运行（Python 3.10+）：

```powershell
.\start-preview.ps1
```

脚本会检查并复用已有预览，或启动本机服务并等待 HTTP 健康检查通过。打开 [春熙路街区](http://127.0.0.1:8765/baidu-map.html)。服务进程停止或机器重启后，重新运行该脚本；不要另开 `http.server`，路线工坊需要本项目预览服务的同源接口。

地图已接入 `digital-jiaozi/` 的完整五个视图与六款票图，以及 `module-a/` 的完整路线规划、行程进度和动态重排能力。个人中心把角色装扮、到访记录、交子钱包和礼品兑换放在一起；体验站每日试玩发放、原地标收藏、兑换与退回共用数字交子的同一账本。地图点亮、模拟移动与路线进度各自保留含义，不会自动发放交子或冒充真实到店。

角色可调整发型和配色，也可拍照或上传照片，经本机裁切与滤镜处理后用于卡通模板头像。这不是 AI 单照生成三维角色，尚未接入外部图像模型。商家发放和礼品领取为本机试玩，不代表正式核销。使用方法、数据来源、构建依赖和真实 WebGL 视觉验收边界见 [地图渲染说明](map-renderer/README.md)；完整体验流程见 [游戏闭环与个人中心](map-renderer/docs/gameplay-integration.md)。

## 原生微信小程序演示

原生微信小程序页面测试，源码位于 `miniprogram/`。当前包含兴趣、预算与时长选择、本地路线生成、模拟打卡和数字交子成长展示。

## 在微信开发者工具中运行

1. 导入本仓库根目录（包含 `project.config.json` 的目录）。
2. 当前配置使用开发者工具提供的测试号，只运行本地演示。其他账号导入时，请在工具中选择自己的测试号或小程序 AppID。
3. 点击编译，打开 `pages/index/index`。不需要安装 npm 依赖。
4. 点击“生成我的逛吃路线”，逐站模拟打卡，再打开底部“我的交子”，检查三个品类完成后是否点亮联动交子。

本节原生小程序演示中的门店、排队、权益和步行时间均为模拟数据。其文本需求仅做本地关键词匹配，尚未接入大模型、地图、微信登录、后端或实际核销。小程序打卡状态仅保留在当前页面会话，重新编译会重置。上方独立 Web 地图的功能与持久化不受此限制。

## 逻辑检查

使用 Node.js 18 或更高版本运行：

```sh
node --test tests/trail.test.js
```

覆盖预算与行程时长约束、免费点位、不可行路线、重复打卡和三品类联动条件。
