# 数字交子 · 手机网页版 Demo

本模块已从微信小程序改为独立 Vite + TypeScript 手机网页。个人旅程、交子钱包、收藏、兑换和照片 Blob 保存在当前浏览器的 IndexedDB；核心功能无需后端、微信登录或 API 密钥。旧小程序/SQLite 后端与旧积分仅归档在 `legacy/`，不参与当前构建。

2026-11-01 地图整合：春熙路地图、玩家中心及完整数字交子页面共用同一个本地钱包。地图商家试玩打卡每商家每日首次 +10 交子（上海时区），可直接兑换原有礼品；六景文化收藏仍各自首次 +10，不因商家打卡自动领取票图。该钱包明确为试玩，尚未接入真实商家核验、线下核销或全局库存。商家目录中的真实地点不表示已签约。

2026-10-31 素材补充：用户提供的六张正式地标票图已接入，编号依票面 CX1001–CX1006 对应 IFS、太古里、九眼桥、大慈寺、水井坊、三圣乡。图片交付后的事实覆盖原改造提示词中“图片未完成、地名未确定”的状态；六景文化收藏保留首次各 10 交子的规则。

## 在哪里运行

实际代码位于当前项目的 `digital-jiaozi/`。完整地图通过 `map-renderer/game-map-jiaozi.mjs` 同源桥接本模块，构建时保留全部收藏、照片、旅程、导出和独立示例功能。

使用 Node.js 22.13+：

```powershell
Set-Location digital-jiaozi
npm ci
npm run dev
```

电脑打开 `http://localhost:5188/#/digital-jiaozi`。本模块固定使用 5188，避免与其他 Vite 项目常用的 5173 混淆；启动后请使用终端实际输出的地址，确认页面标题为“数字交子 · 我的旅行记忆”。手机和电脑连接同一局域网，将 localhost 换成开发电脑的局域网 IP；允许本机开发端口通过防火墙。HTTP 局域网预览有相册与拍照文件选择回退，剪贴板及系统拍照能力以手机浏览器支持为准。不要把 LAN 地址当正式 NFC 入口。

## 本期规则

- 六款平等地标票，每款文化任务首次打卡 10 交子，该项最多 60。按活动+地标去重，事件重放和多标签并发不会重复奖励。
- 地图配置的每个商家每天首次试玩打卡 10 交子，按活动+商家+上海日期去重；与六景收藏共用钱包，商家收入另计，不占六景收藏上限。事件重放跨天也不会重新发放旧事件。
- 同时显示累计获得和可用余额；兑换只消费余额，地图和收藏保持不变，无等级、升级或旧积分任务。
- Demo 礼品 20/30/40/50/60 交子。60 交子是固定款 NFC 实体纪念交子冰箱贴，不是升级形态；没有真实库存或发货承诺。
- 待领取兑换可取消退回一次，累计获得不增加；演示确认领取后不能取消。
- 照片上传、裁剪、旋转、彩色/单色/线条处理在本地完成，成品以 PNG Blob 保存，不奖励交子。无 AI 配置时手动命名可完整使用。
- 地标演示打卡和宿主文化任务输入明确区分；宿主输入只是本地适配接口。地图商家仅接受 `source:'demo'`，未实现真实 GPS 认证、可信货币、工作人员核销或跨设备恢复。

地图部署时在项目根目录运行 `node map-renderer/scripts/build_jiaozi.mjs`，会先进行类型检查和生产构建，再将完整站点原子替换到 `map-renderer/assets/digital-jiaozi/`。IndexedDB 从 v1 升为 v2 时只新增商家记录表，现有余额、累计、票图、照片 Blob、旅程及流水数值不变；没有创建另一个地图钱包。独立示例继续使用另一数据库，嵌入地图时在新窗口打开，不替换个人钱包。

## 生产构建与静态部署

```powershell
npm run check
npm test
npm run build
npm run build:module
npm run test:browser
npm run preview
```

`dist/` 是独立站点，可把其中内容上传到静态服务器的根目录或子目录；`dist-module/` 是给队友的 ES 模块和 CSS。构建产物不进 Git。默认 Vite base 为 `./`，生产浏览器测试实际部署在 `/preview/` 子路径下并直接打开深链接。

若部署目标要求固定绝对 base：

```powershell
$env:DJ_BASE = '/team/digital-jiaozi/'
npm run build
Remove-Item Env:DJ_BASE
```

路由位于 hash 内，静态服务器只需正常返回该部署目录的 `index.html`，无需为 hash 路由设置服务器 rewrite。不支持直接双击本地 HTML 的 file 协议。

## NFC 最终网址与保存

以下域名只是格式示例，应替换为实际长期稳定的 HTTPS 部署地址：

- 通用入口：`https://example.org/team/digital-jiaozi/#/digital-jiaozi/journey`
- 专属入口：在“旅程纪念”保存后复制页面生成的 `journeyId` 网址。
- 本机标签：先保存旅程，再输入 tagId 绑定并复制对应网址；绑定只存在当前浏览器。

把最终网址作为 URL 写入 NFC 标签。NFC 只让系统打开网址，网页不读取 NFC 硬件，也不需要 Web NFC/微信 SDK。标签不包含照片、完整路线或密钥。

每次保存创建独立旅程快照，保留当时路线、到访顺序、地标展示字段和照片引用；继续领取或再保存不会覆盖旧快照和旧 journeyId。无参数入口恢复最近保存快照。指定不存在的 journeyId/tagId 会显示“当前浏览器暂无这段旅程”，不会替换成别的记录。

必须使用同一手机、同一浏览器/用户配置、同一网站 origin。更换域名、协议、端口、浏览器或清除网站数据不会自动恢复。网站子路径不隔离 IndexedDB；独立示例使用另一数据库，重置示例不清个人记录。浏览器可能因清理或空间不足移除本地记录；本 Demo 没有云备份。导出的纪念 PNG 是图片，不是可重新导入的旅程备份。

**本轮验证了桌面 Edge 打开同一 URL 恢复记录；尚未实测手机碰 NFC、手机系统实际拍照或 iOS Safari。**

## 评委体验顺序

1. 用演示手机碰 NFC，或先打开通用旅程网址。首次显示暂无保存记录。
2. 进入“地标收藏”，使用标明“演示打卡”的按钮领取；无需真的走完六个景点。
3. 看“我的交子”地图和交子余额、点击票面看完整正式图片；可上传自己的照片生成图案。
4. 领取六款可得到 60 交子，兑换 20 交子礼品后余额 40，累计 60、地图六款仍保留。若要演示 60 交子 NFC 礼品，先取消待领取的 20 交子订单退回余额，或使用独立示例档案。
5. 进入“旅程纪念”，主动选示例路线或接入队友真实路线快照，填写名称并保存。复制专属网址或绑定本机 tagId。
6. 关闭页面，再次碰写有通用/专属网址的 NFC，使用相同浏览器恢复。需要按实际地址写卡，编码完成不会自动替你改标签内容。
